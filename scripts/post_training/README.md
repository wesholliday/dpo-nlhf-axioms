# Actual Post-Training

This package contains empirical DPO and Nash-MD LoRA training scripts used to compare actual post-training behavior with the closed-form RTBT and NLHF predictions.

The command-line defaults are generic unless a script help string says
otherwise.  To reproduce the paper outputs, use the explicit commands in the
repository `README.md` or the hyperparameters recorded in the curated
`results/empirical/**/*_meta.json` files.
